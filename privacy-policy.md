# Privacy Policy — Download Manager Pro

**Last updated:** 2024-01-01

## Overview
Download Manager Pro is committed to protecting your privacy.

## Data Collection
This extension does **not** collect, transmit, store on remote servers,
or share any personal data whatsoever.

## Data Storage
All data (settings, triggers, queue state) is stored **locally** on your
device using the browser's Storage API (`chrome.storage.local`).
No data ever leaves your device.

## Network Requests
This extension makes **zero** network requests. It does not connect to
any external server, API, or analytics service.

## Permissions Explained

| Permission | Why It's Needed |
|---|---|
| `downloads` | Core functionality — monitor and manage downloads |
| `downloads.open` | Open completed files when trigger is set |
| `storage` | Save your settings and triggers locally |
| `notifications` | Show desktop alerts for download events |
| `alarms` | Schedule auto-retry timers and queue management |
| `nativeMessaging` (optional) | Only if you install the shutdown helper |

## Browser Compatibility
This extension works identically across Chrome, Edge, Brave, Opera,
Vivaldi, and other Chromium-based browsers. No browser-specific data
collection occurs.

## Third-Party Code
This extension contains no third-party libraries, trackers, or
analytics code.

This policy may be updated. Changes will be reflected in the
